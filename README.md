### Introducción

La noche del 31 de octubre, a las 23:45, una anomalía
aparece en la sala de servidores. Un antiguo desarrollo
maldito ha regresado al historial y amenaza con corromper
el sistema de producción.

William Crowe debe reconstruir el repositorio, estudiar
dos líneas temporales, resolver un conflicto y eliminar
la infección antes de medianoche.

El objetivo técnico es demostrar el uso de commits,
ramas, fusiones, resolución de conflictos, inspección
de diferencias y restauración de una versión segura.
